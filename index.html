Публикация в сеть

Работа с сервером

fetch, JSON и две главные ловушки

Помните: fetch отклоняет промис только при обрыве сети. Статусы 404 и 500 нужно проверять вручную через response.ok.

Правила JSON

Общий язык клиента и сервера

  • Ключи и строки — только в двойных кавычках.
  • Числа, true, false, null — без кавычек.
  • Запрещены комментарии и запятая после последнего элемента.
  • JSON.parse() — из строки в объект, JSON.stringify() — обратно.
safeFetch.js · Эталонный шаблон 
async function loadUser(login) {
  try {
    const res = await fetch(`https://api.github.com/users/${login}`);
    if (!res.ok) throw new Error(`HTTP ошибка: ${res.status}`);
    return await res.json();
  } catch (err) {
    console.error('Сбой загрузки:', err);
    return null;
  }
}
